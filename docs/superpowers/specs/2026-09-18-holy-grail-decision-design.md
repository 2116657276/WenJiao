# 圣杯抉择器 (Holy Grail Decision) 设计规范文档

- **项目名称**：圣杯抉择器 (Holy Grail Decision)
- **目标平台**：macOS 原生轻量 App（基于 Swift + 系统原生 WKWebView，极小体积与超低内存）+ 纯前端（HTML5/CSS 3D/JS）
- **设计定位**：现代极简、无迷信色彩、兼具东方仪式感与物理动效的个人本地随机决策工具。

---

## 一、 系统架构与极轻量技术栈

### 1. 技术栈选型
* **展示与交互引擎**：纯原生前端技术栈（HTML5 + CSS 3D Transforms + Web Animations / requestAnimationFrame + 原生 JS）。
  * 零框架（无 React / Vue），零外部依赖，极速冷启动。
  * 零外部音频素材：木质筊杯落地与撞击音效采用 Web Audio API 原生合成器算法即时生成（木音振荡 + 敲击带通滤波），零网络加载。
* **数据持久化**：
  * 基于原生 `localStorage` 本地沙箱持久化，保存历史决策流水与常用预设，关掉 App 或重启系统永不丢失。
  * 提供「导出记录为 JSON」与「一键重置清空」功能。
* **桌面端封装方案**：
  * 采用 macOS 系统内置编译器 `swiftc`，编写数十行纯 Swift 原生微型外壳（约 200KB 二进制体积）。
  * 直接接入 macOS 原生 `WKWebView`，共享系统 WebKit 运行时，**内存占用仅 ~25MB**（远低于 Electron 的 200MB+），无需用户安装任何额外环境。
  * 打包为开箱即用的 `圣杯抉择器.app`，放置在文件夹或拖入 Applications 即可使用。

## 二、 核心数学逻辑与状态机

### 1. 传统模式 (Traditional Mode)
* **投掷机制**：单次独立随机产生两个筊杯各自的正反面（每面 50% 阴，50% 阳）。
* **单次结果判定**：
  * **圣杯**（一阴一阳）：概率严格 **50%**。
  * **笑杯**（两阳）：概率严格 **25%**。
  * **阴杯**（两阴）：概率严格 **25%**。
* **决策分支**：
  * **默认规则**：
    * 圣杯 → 决策选择 **A**，本轮立即结束。
    * 阴杯 → 决策选择 **B**，本轮立即结束。
    * 笑杯 → 本次无最终决定，允许用户继续点击掷杯。
  * **开启连续三圣规则（可选开关）**：
    * 只有每次用户主动点击才会投一次（禁止自动后台跑完）。
    * 连续第 1 次圣杯 → 显示进度 `1/3`（不产生 A/B）。
    * 连续第 2 次圣杯 → 显示进度 `2/3`（不产生 A/B）。
    * 连续第 3 次圣杯 → 三圣达成，最终选择 **A**，本轮结束。
    * 中途只要出现笑杯或阴杯 → 连续中断，最终选择 **B**，本轮结束。
    * *界面标注提醒*：传统连续三圣下 A 的理论达成概率仅为 $0.5^3 = 12.5\%$，此模式规则天然显著偏向 B。

### 2. 公平三圣模式 (Fair Triple-Sacred Mode)
* **设计目标**：三连圣才选 A，中途断则选 B，且最终选 A 与选 B 的总概率**数学上严格各为 50%**。
* **单次概率计算**：
  * 设单次圣杯概率为 $p$，则 $p^3 = 0.5 \implies p = \sqrt[3]{0.5} \approx 0.793700526$ ($79.37005\%$)。
  * 剩余概率 $1 - p \approx 0.206299474$ ($20.62995\%$)，由笑杯与阴杯各平分一半：
    * 圣杯：$79.3700526\%$
    * 笑杯：$10.3149737\%$
    * 阴杯：$10.3149737\%$
* **视觉映射逻辑**（先确定结果，再映射图形）：
  * 随机数落在圣杯区间 $\implies$ 视觉随机显示 `[阴, 阳]` 或 `[阳, 阴]`。
  * 随机数落在笑杯区间 $\implies$ 视觉显示 `[阳, 阳]`。
  * 随机数落在阴杯区间 $\implies$ 视觉显示 `[阴, 阴]`。
* **跨点击累计流转**：
  * 第 1 投：若圣杯 $\to$ 进度 `1/3`，不输出 A/B；若笑/阴杯 $\to$ 直接中断，最终选择 B。
  * 第 2 投：若圣杯 $\to$ 进度 `2/3`，不输出 A/B；若笑/阴杯 $\to$ 连续中断，最终选择 B。
  * 第 3 投：若圣杯 $\to$ 进度 `3/3`，三圣成立，最终选择 A；若笑/阴杯 $\to$ 连续中断，最终选择 B。

## 三、 视觉形象与 3D 物理交互动效

1. **筊杯外观与材质**：
   * 采用东方红木/深红微漆质感（沉稳雅致，非刺眼大红）。
   * 阴面（平面）：温润木质平面，边缘圆滑倒角。
   * 阳面（凸面）：优美的月牙形拱形立体隆起，带动态光影高光。
2. **抛掷与物理落定动效**：
   * **起跳与腾空**：点击「掷一次」或按空格键，两枚筊杯以不同初速度飞入空中，高度上升，投影动态模糊拉大。
   * **三维翻转**：在 3D 透视视口内以随机扰动的角速度进行多圈自由立体翻滚（Yaw / Pitch / Roll）。
   * **阻尼弹跳（Bounce Decay）**：接触桌面时触发 2~3 段弹性阻尼衰减动画。若阳面朝下（凸面朝下），会有额外的轻微滚动余颤后静止。
   * **防抖限制**：在投掷动画期间（约 0.9s ~ 1.1s），投掷按钮处于禁用状态，避免连击导致状态错乱。
3. **触觉与听觉反馈**：
   * 伴随落地弹跳时机的 Web Audio 合成撞击音效。

## 四、 界面布局与防误触机制

1. **整体布局（竖向独立窗口，420px × 680px）**：
   * **顶栏**：模式切换 Tabs（【传统模式】/【公平三圣 50%】），附模式说明浮层；声音开关。
   * **决策输入区**：
     * 问题输入框（可选，如“今晚吃火锅还是烤肉？”）。
     * 选项 A 与 选项 B 文本框（默认：“是 / 否” 或 “去 / 不去”）。
   * **核心投掷区（占位 3D 舞台）**：
     * 展示两只三维筊杯、投影及落地盘面。
     * 当前轮次状态标签（如“第 2 投 · 进度 2/3”）。
   * **控制区**：
     * 主按钮：“掷一次 (Space)”；本轮结束时切换为高亮按钮：“开始下一轮”。
   * **历史流水抽屉 / 折叠面板**：
     * 严格区分「单次投掷明细」（如：`#1 圣杯 (1/3)`）与「最终决策结果」（如：`🏆 最终判定: 选项 A [去]`）。
2. **防状态混淆保护**：
   * 当处于某一轮进行中（如公平模式已投 1/3 或 2/3）时，如果用户修改选项 A/B、切换模式或更改“连续三圣”开关：
     * 弹出二次确认提示：“当前轮次已进行中，修改将重置本轮进度，是否继续？”。
     * 避免逻辑状态静默污染。

## 五、 文案规范与风格基调
* **严格去迷信化**：禁止出现“神明指示”、“天意”、“签文”等词汇。
* **采用中性科学的决策文案**：
  * 状态：“随机决策推演中”、“连续三圣达成”、“连续条件中断”、“决策已收敛”。
  * 提示：“基于大数定律与纯随机数发生器，助您破除选择焦虑”。
